# Workshop preview

With the local Console running, open `/workshop-preview.html`.
The preview uses the real Workshop components with synthetic fetch and event responses.
It has no API fallback, does not load authentication, and is not a production build entry.

Expand a row or change the canvas zoom, then select **Play updates**. Use **Next update**
to advance manually, **Replay loading** to start again, and **Simulate refresh failure**
to see retained cells with a retry notice. No dataset or training job is created.
