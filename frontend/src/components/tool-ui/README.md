# Tool UI

Chart and DataTable are adapted from [assistant-ui/tool-ui](https://github.com/assistant-ui/tool-ui/tree/main/apps/www/components/tool-ui), source revision `49a870286facdbf28160cd647f0d337ebdc9b275`, MIT © 2025 AgentbaseAI Inc. (see LICENSE.md). The components use Overmind's Card and semantic tokens and extends the upstream bar/line renderer with area, horizontal bar, pie and scatter to preserve Workshop capabilities.

Workshop results are registered as assistant-ui data parts. The backend's validated presentation document supplies the component vocabulary and retained values; browser code never executes model-generated JavaScript. Follow-up forms retain the existing native Workshop delivery contract.
