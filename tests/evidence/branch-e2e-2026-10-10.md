## Reproduction

Compose Postgres/Redis services, Chromium for Console journeys, Docker access and
the Workshop runtime image. Live tests additionally require the saved
endpoint-bound local account connection, the source cells and retained packages
referenced by the scripts, and development Modal credentials. Do not replace the
local endpoint with a hosted endpoint. Live preparation/training consumes compute.

From the repository root, create `/private/tmp/branch_e2e_settings.py` containing:

```python
from tests.settings import *  # noqa: F403

DATABASES["default"]["NAME"] = "branch_e2e_20261010"
```
